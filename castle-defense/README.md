# 산성 수호전

성곽을 키워 고을을 지키는 고전 성지키기(육성형 타워 디펜스) 웹 게임입니다. `index.html` 한 파일로 돌아가며 빌드 과정이 없습니다.

## 실행

- 브라우저로 `castle-defense/index.html`을 열면 바로 플레이할 수 있습니다.
- GitHub Pages를 켜 두었다면 `https://<사용자>.github.io/<저장소>/castle-defense/` 주소로 열립니다.

## 게임 구성

| 요소 | 내용 |
| --- | --- |
| 출정 (스테이지) | 4개 지역 × 5관문 = 20관문. 5·10·15·20관문에 두령(장군 도깨비, 구미호, 이무기, 불가사리)이 나옵니다. 남은 성벽 내구도로 별 1~3개를 받습니다. |
| 육성 | 엽전으로 장수(공격력·속사·다발 화살·치명타), 성벽(내구도·방비·보수), 방어탑(궁수대·화차·총통·도사), 술법(불화살 비·벼락 부적·결계진), 내정(세곡 징수·봉화 연락)을 올립니다. 져도 전리품은 남습니다. |
| 랭킹전 | 제 3관문을 돌파하면 열립니다. 끝없이 강해지는 파를 버틴 만큼 점수가 오르며, 지금 육성 상태로 출전합니다. |

조작: 전장을 누르고 있으면 장수가 그 지점으로 활을 쏩니다(스페이스도 됨). `1` `2` `3` 술법, `P` 잠시 멈춤, `F` 배속.

## 저장과 랭킹

- 진행 상황과 "이 기기" 랭킹은 브라우저 `localStorage`에 저장됩니다.
- claude.ai 아티팩트로 열면 공유 저장소(`window.claude.use("db")`)에 연결되어 온라인 랭킹(`rank/<사용자 id>`, 한 사람당 최고 기록 하나)과 계정별 진행 저장(`data/users/<id>/save`)이 켜집니다.
- 일반 웹 호스팅(GitHub Pages 등)에서 누구나 참여하는 온라인 랭킹을 쓰려면 Firebase·Supabase 같은 별도 백엔드를 `Cloud` 객체의 `init`/`submit`에 연결해야 합니다. 점수는 브라우저에서 계산되므로 공개 랭킹이라면 서버 쪽 검증도 함께 고려하세요.

## 개발용

주소 끝에 `#dev`를 붙여 열면 `window.__ssj`로 상태를 살피고 엽전 지급(`give`)·관문 해금(`clearTo`) 같은 테스트 도구를 쓸 수 있습니다.
