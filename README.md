# 태권도 통합 관리

도장 하나를 운영하는 데 필요한 일을 한 앱에 모았습니다. 원생 100명 규모를 기준으로 만들었습니다.

앱 주소: **https://awoolimtkd.github.io** · 사용설명서: **https://awoolimtkd.github.io/manual.html**

무료로 다른 도장에 나눠 줄 수 있게 만들었습니다. 앱 주소는 모든 도장이 같고, 자료는 **도장마다 자기 Firebase 프로젝트**(관장님 구글 계정)에 저장됩니다. 앱을 만든 사람은 다른 도장의 자료를 볼 수 없습니다.

| 화면 | 쓰는 사람 | 하는 일 |
|---|---|---|
| 출석체크 (키오스크) | 아이들 | 도장 태블릿·공기계에서 출석번호 4자리를 눌러 출석 |
| 관리자 | 관장·사범님 | 원생, 출석부, 회비장부, 체력측정, 알림장, 참가신청, 승급심사, 설정 |
| 학부모 | 어머님·아버님 | 우리 아이 출석 달력, 알림장(답글), 참가신청서(서명), 체력·승급심사 결과, 회비 납부 내역 |

## 기능

- **출석체크**: 4자리 번호 입력 → 이름·띠·이번 달 출석 횟수 표시, 같은 날 두 번 출석 방지, 소리·진동, 화면 꺼짐 방지. 관리자 비밀번호 없이는 출석 화면을 나갈 수 없습니다.
- **출석부**: 일별 체크(반별 묶음, 미출석만 보기), 월별 표(칸을 눌러 수정). 1주일 넘게 안 나온 원생은 홈에 따로 표시합니다.
- **회비장부**: 월별 청구·납부·미납 합계, 납부 처리(계좌이체/카드/현금/면제), 원생별 회비(형제 할인), 기타 수입(심사비·대회비·용품), 엑셀(CSV) 내보내기, 미납자에게 알림장 보내기.
- **체력측정**: 반 단위로 표에 바로 입력(Enter로 다음 칸), 지난번 대비 변화, 같은 나이 원생과 비교한 육각형 그래프, 항목별 TOP 10. 측정 항목은 설정에서 바꿀 수 있습니다.
- **어머님 알림장**: 전체·반별·개별 발송, 사진 1장, 자주 쓰는 글, 읽음 확인, 학부모 답글.
- **참가신청서**: 대회·승급심사·캠프 행사 만들기, 선택 항목(부문 등)·추가 질문, 보호자 동의·손글씨 서명, 신청자 명단, 참가비 납부 표시(회비장부에 함께 기록), 명단 내보내기.
- **승급심사 결과증**: 기존 `심사체점시스템` 페이지의 채점표 10항목·급수기준·육각형 계산을 그대로 옮겼습니다. 결과증 이미지 저장·공유, 합격 시 급수 올리기, 승급심사 신청자로 채점표 만들기.

## 실행해 보기

```bash
npm start            # http://localhost:8090 에서 열립니다
npm run build        # dist/taekwondo.html 한 파일로 묶기
npm run deploy       # www/ 를 웹 주소용 저장소(GitHub Pages)에 올리기 (tools/deploy.mjs 의 SITE)
npm run manual:pdf   # 설명서 PDF(www/manual.pdf, www/parents.pdf) 다시 만들기. 설명서를 고치면 같이 돌려 주세요
```

처음 열면 체험용 샘플 데이터(원생 100명)가 들어 있습니다.

- 관리자 비밀번호: `123456` (설정에서 바꿀 수 있습니다. 5번 틀리면 5분 잠기고, 10분 동안 안 쓰면 자동으로 잠깁니다)
- 학부모 체험 계정: 시작 화면 아래에 표시된 휴대폰 번호와 출석번호
- 실제로 쓸 때는 **설정 → 데이터 → 샘플 지우고 새로 시작**을 누른 뒤 원생을 등록하세요.

## 개인정보 보호

- **전자 동의서 (종이 동의서 대신)**: 필수(수집·이용)와 선택(사진, 건강 정보)을 나눠 받고, 만 14세 이상은 원생 본인 동의도 받습니다. 보호자 성함·관계·서명과 동의 시각이 원생 정보에 남습니다.
  - 도장에서 직접: 원생 등록 직후 이 기기에서 보호자가 읽고 서명합니다.
  - 학부모 앱: 처음 로그인하면 동의서가 먼저 나오고, 동의해야 앱을 쓸 수 있습니다. 동의 뒤 관리자 홈의 "확인 문자"로 보호자 휴대폰에 동의 확인 문자를 보냅니다(만 14세 미만 법정대리인 확인).
  - 선택 항목은 학부모가 앱 메뉴에서 바로 철회할 수 있고, 사진 동의가 없으면 사진을 올릴 수 없습니다.
- **백업 암호**: 백업 파일은 관장님이 정한 비밀번호(8자 이상)로 AES-256 암호화해서 만듭니다. 비밀번호를 잊으면 열 수 없습니다.
- **개인정보 처리방침**: 앱이 실제로 다루는 정보에 맞춰 자동으로 만들어집니다(개인정보보호위원회 작성지침 항목 순서). 설정에서 보호책임자 이름·연락처를 넣으면 반영되고, 시작 화면·학부모 메뉴·참가신청서에서 볼 수 있습니다.
- **참가신청서 동의**: 개인정보 수집·이용 동의(필수)를 따로 받고, 대회 주최 측에 정보를 넘기는 행사는 받는 곳·항목·보유 기간을 보여 주고 제3자 제공 동의를 따로 받습니다. 동의 시각이 신청서에 남습니다.
- **관리자 잠금**: 6자리 비밀번호, 5번 틀리면 5분 잠금, 쓰지 않으면 자동 잠금(5·10·30분).
- **보관 기간**: 퇴원 후 1년, 행사 종료 후 1년이 지나면 홈에 알림이 뜨고 "개인정보 정리"로 지웁니다. 회비 금액 기록은 장부 보관을 위해 이름 없이 남깁니다.

## 데이터 저장

연결한 서버가 없으면 **체험 모드**로, 모든 정보가 **그 기기 안에만** 저장됩니다(IndexedDB, 샘플 원생 100명).
도장 서버에 연결하면 **그 도장의 Firebase 서버(서울)** 에 저장되고 도장 태블릿·관장님·학부모 휴대폰이 같은 자료를 실시간으로 봅니다.

- **어느 서버에 붙을지는 기기마다 기억합니다**(`www/firebase-config.js`, 저장 키 `tkd-server-v1`). 관장님은 앱에서 Firebase 설정값을 붙여 넣고, 다른 기기는 연결 링크 `?s=프로젝트ID.API키.앱ID`로 엽니다.
- **학부모 초대 문자**에는 연결 링크와 초대 코드가 함께 들어갑니다(`&c=코드`). 링크를 열면 서버가 연결되고 코드가 채워집니다.
- 다른 도장의 링크로 열면 바꿀지 먼저 묻습니다. **설정 → 이 기기 서버 연결 해제**는 로그인과 기기에 남은 사본까지 지웁니다.
- 처음 설정 방법은 [사용설명서](www/manual.html)(관장님용)와 [docs/firebase-setup.md](docs/firebase-setup.md)에 있습니다.

체험 모드에서는 다른 휴대폰과 공유되지 않으니, 기기를 바꾸기 전에 **설정 → 백업 파일 만들기**로 백업해 두세요.
예전 `승급심사 결과증` 페이지를 같은 주소에서 쓰던 기록이 있으면 처음 열 때 자동으로 가져옵니다(예전 주소 gyeoltaro.github.io 와 새 주소는 저장공간이 달라서, 새 주소에서는 가져오지 않아요).

## 서버 모드 (2단계)

- **관리자**: 이메일·비밀번호 로그인 + 이메일 인증. 보안 규칙에 적힌 이메일만 관리자입니다.
- **학부모**: 도장이 문자로 보낸 **초대 코드(8자리, 7일, 1회용)** 로 기기를 연결합니다. 학부모 이름·전화번호는 로그인 서버에 넘어가지 않습니다.
- **보안 규칙**(`www/js/cloud-rules.js` → `npm run rules 이메일`): 학부모는 자기 아이 자료만 읽고, 동의서·신청서·읽음 표시·답글만 쓸 수 있습니다.
- **동기화**(`www/js/cloud.js`): 화면 코드는 그대로 두고, 바뀐 부분만 문서 단위로 올리고 다른 기기의 변경을 실시간으로 받습니다. 인터넷이 끊겨도 기기에 적어 두었다가 연결되면 올립니다.
- 학부모 화면의 체력 또래 비교는 이름 없는 나이별 통계(5명 이상 묶음)로 계산합니다.

## 앱 푸시 (선택)

- **보내는 쪽**: `functions/` (Firebase Cloud Functions 2세대, 서울 리전). 새 알림장·오늘 출석 → 그 아이 학부모 기기, 학부모 참가신청·답글 → 관리자 기기. 도장 설정의 "앱 푸시 사용"이 켜져 있을 때만, 아이 이름 없이 보냅니다.
- **받는 쪽**: 학부모·관리자가 앱에서 "알림 켜기"를 누르면 기기의 알림 주소(FCM 토큰)를 `push/{uid}`에 저장합니다(보안 규칙: 자기 것만). `www/sw.js`가 알림을 보여 줍니다. 아이폰은 홈 화면 아이콘에서만(iOS 16.4+).
- **설치**: Firebase를 Blaze 요금제로 바꾸고(예산 알림), Google Cloud Shell에서 `curl -fsSL https://awoolimtkd.github.io/push-server/install.sh | bash` 한 줄(`tools/push-install.sh`, 첫 설치 때 나는 Eventarc 권한 준비 오류는 자동 재시도). 개발 PC에서는 `npm run deploy:push -- --project 프로젝트ID`.
- `firebase.json`에는 functions와 에뮬레이터만 있습니다. `firebase deploy`가 실수로 보안 규칙(예시 이메일)을 덮어쓰지 않게 하려는 것입니다.
