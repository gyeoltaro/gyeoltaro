# 태권도 통합 관리

도장 하나를 운영하는 데 필요한 일을 한 앱에 모았습니다. 원생 100명 규모를 기준으로 만들었습니다.

| 화면 | 쓰는 사람 | 하는 일 |
|---|---|---|
| 출석체크 (키오스크) | 아이들 | 도장 태블릿·공기계에서 출석번호 4자리를 눌러 출석 |
| 관리자 | 관장·사범님 | 원생, 출석부, 회비장부, 체력측정, 알림장, 참가신청, 승급심사, 설정 |
| 학부모 | 어머님·아버님 | 우리 아이 출석 달력, 알림장(답글), 참가신청서(서명), 체력·승급심사 결과, 회비 납부 내역 |

## 기능

- **출석체크**: 4자리 번호 입력 → 이름·띠·이번 달 출석 횟수 표시, 같은 날 두 번 출석 방지, 소리·진동, 화면 꺼짐 방지. 관리자 비밀번호 없이는 출석 화면을 나갈 수 없습니다.
- **출석부**: 일별 체크(반별 묶음, 미출석만 보기), 월별 표(칸을 눌러 수정). 1주일 넘게 안 나온 원생은 홈에 따로 표시합니다.
- **회비장부**: 월별 청구·납부·미납 합계, 납부 처리(계좌이체/카드/현금/면제), 원생별 회비(형제 할인), 기타 수입(심사비·대회비·용품), 엑셀(CSV) 내보내기, 미납자에게 알림장 보내기.
- **체력측정**: 반 단위로 표에 바로 입력(Enter로 다음 칸), 지난번 대비 변화, 같은 나이 원생과 비교한 육각형 그래프, 항목별 TOP 10. 측정 항목은 설정에서 바꿀 수 있습니다.
- **어머님 알림장**: 전체·반별·개별 발송, 사진 1장, 자주 쓰는 글, 읽음 확인, 학부모 답글.
- **참가신청서**: 대회·승급심사·캠프 행사 만들기, 선택 항목(부문 등)·추가 질문, 보호자 동의·손글씨 서명, 신청자 명단, 참가비 납부 표시(회비장부에 함께 기록), 명단 내보내기.
- **승급심사 결과증**: 기존 `심사체점시스템` 페이지의 채점표 10항목·급수기준·육각형 계산을 그대로 옮겼습니다. 결과증 이미지 저장·공유, 합격 시 급수 올리기, 승급심사 신청자로 채점표 만들기.

## 실행해 보기

```bash
npm start            # http://localhost:8080 에서 열립니다
npm run build        # dist/taekwondo.html 한 파일로 묶기
```

처음 열면 체험용 샘플 데이터(원생 100명)가 들어 있습니다.

- 관리자 비밀번호: `1234` (설정에서 바꿀 수 있습니다)
- 학부모 체험 계정: 시작 화면 아래에 표시된 휴대폰 번호와 출석번호
- 실제로 쓸 때는 **설정 → 데이터 → 샘플 지우고 새로 시작**을 누른 뒤 원생을 등록하세요.

## 데이터 저장

1단계에서는 모든 정보가 **그 기기 안에만** 저장됩니다(IndexedDB). 다른 휴대폰과는 아직 공유되지 않으니, 기기를 바꾸기 전에 **설정 → 백업 파일 만들기**로 백업해 두세요.
예전 `승급심사 결과증` 페이지를 같은 주소에서 쓰던 기록이 있으면 처음 열 때 자동으로 가져옵니다.

## 폴더 구조

```
www/                 앱 본체 (나중에 APK로 포장할 폴더)
  index.html
  css/app.css
  js/
    util.js          날짜·금액 포맷, 이미지 줄이기, 파일 저장
    store.js         데이터 저장소 (2단계에서 서버로 바꿀 곳)
    seed.js          체험용 샘플 데이터
    ui.js            아이콘, 모달, 비밀번호 입력, 원생 선택, 서명, 그래프
    kiosk.js         출석체크 화면
    admin-home.js    관리자 홈
    students.js      원생
    attendance.js    출석부
    fees.js          회비장부
    fitness.js       체력측정
    notices.js       알림장
    events.js        참가신청서
    exams.js         승급심사 결과증
    settings.js      설정
    parent.js        학부모 화면
    app.js           화면 이동, 뒤로가기(안드로이드 뒤로 버튼 포함)
tools/build.mjs      한 파일 HTML로 묶기
```

## 다음 단계

1. **서버 연결 (2단계)**: Firebase(로그인·데이터베이스)로 출석 태블릿, 관장님 휴대폰, 학부모 휴대폰이 같은 데이터를 봅니다. `www/js/store.js`의 저장·불러오기 부분만 바꾸면 됩니다.
2. **앱 푸시**: Firebase Cloud Messaging(무료)으로 등원 알림, 새 알림장, 신청 마감 알림을 보냅니다. 카카오 알림톡·문자와 달리 건당 비용이 없습니다.
3. **APK (3단계)**: Capacitor로 `www/` 폴더를 안드로이드 앱으로 포장합니다. 화면 코드는 그대로 씁니다.
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "태권도 통합관리" kr.dojang.taekwondo --web-dir www
   npx cap add android && npx cap sync
   ```
   APK는 안드로이드 전용이라 아이폰을 쓰는 학부모님께는 같은 화면을 웹 주소로 열어 드리면 됩니다.
