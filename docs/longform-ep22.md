- 왜 이 주제: LF.21 큐 메모의 후보 셋(① 시장 잡화 노점 재고 회전 ② 타이어·카센터 공임 ③ 횟집 '한 병 덜')은 원문(시장 묶음 가격 · 소비자원 공임 · 국세청 출고량)을 아직 못 열어 대기로 두고, 11.15 공부 후보 1번 **'빈 상가 1층 — 건물주는 월세를 깎느니 비워 둔다(월세 = 건물값)'** 을 골랐다. 핵심 계산(수익환원율 4% · 월세 300만 → 9억, 250만 → 7억 5,000만)이 국민일보 2025.12.4 원문에 그대로 있고, 공실률·임대가격지수는 한국부동산원 2026년 2·3분기 조사를 인용한 보도 3건으로 확인돼 근거가 충분했다. 반전 '월세를 못 내리는 쪽도 건물주 사정(수익환원)'은 CLAUDE.md 반전 목록에 없고 어제(대출 원금)와 겹치지 않는다. 쇼츠 EP.08 스터디카페(건물주가 진짜 승자)·LF.07 과는 주체가 같지만 반전 방향이 다르다(건물주가 가져가는 몫 → 건물주가 못 내리는 이유).
- 첫 30초: 1층 월세 300만 원, 반년째 비었는데 한 푼도 안 깎는다 → 50만 원만 깎으면 들어온다는 사람이 있다 → 반년 손해 2,000만 원이 넘는데? → 건물주 계산기로는 50만 원 깎는 순간 1억 5,000만 원(첫 답 약 0:17) → 월세가 곧 건물값.
- 중심 그림: **월세 만 원짜리 한 장 = 건물값 벽돌 한 칸(300만 원).** 월세 300만 원 = 벽돌 300칸(20 × 15) = 9억 원. 50만 원을 깎으면 아래 50칸이 빨갛게 떨어진다. 그 밖에 상표 없는 3층 건물(1층 '임대' 종이), 1층 가게 한 칸(빈 자리 / 영업 중), 만 원 지폐 그림(실제 도안 아님), 계산기, 저울 막대(2,040만 vs 1억 5,000만), 비워 둔 달 수 그래프(9개월 · 44개월), 첫해 12달 달력(석 달 0원), 상가 임대차 계약서, 1층 100곳 격자(7곳 빈 자리).
- **상가 월세·수익률·관리비는 전부 예시 가정이다.** 월세 300만·수익률 4%는 국민일보 예시와 같은 숫자로 맞췄다(영상에서 '한 보도도 똑같이' 라고 밝힘). 제안 월세 250만, 비어 있는 동안 고정비 월 40만(항목은 디지털데일리 보도), 렌트프리 석 달, 보증금·세금 제외.

## 업로드 문구 (YouTube 스튜디오에 그대로 붙여 넣기)

`docs/title-thumbnail-playbook.md` 로 짰다. **A안 = T6 역설 + 금액 · S1 + S6 숫자를 계산기 화면에**("월세 50만 원 깎으면 건물값 1억 5천 증발(?)"), **B안 = 시험 대기 1순위 T1 따옴표 · S4 따옴표 글씨 + S2 빈 가게 '임대' 종이**("월세 깎으면 건물값이 떨어져요" — 보도 속 건물주 생각을 옮긴 예시 대사, 실존 인물 발언 아님), C안 = T2 모순 · S5 걱정하는 계산이를 빈 가게 옆에 + 쪽지(공실 6개월 −2,040만 / 인하 −1억 5천). 세 안 모두 같은 숫자(월세 −50만 → 건물값 −1억 5,000만)다. 상가 공실은 쇼츠로 다룬 업종이 아니지만, 손님이 아니라 **동네를 걷는 누구나 보는 장면**('임대' 종이)이라 플레이북 가설 1(손님이 직접 쓰는 업종)의 변형 표본이다.

- 대안 B안 (썸네일 B와 짝) [T1]: `"월세 깎으면 건물값이 떨어져요" 반년 비워 둔 1층 상가 계산서 | 50만 원 = 1억 5,000만 원`
- 대안 C안 (썸네일 C와 짝) [T2]: `빈 가게는 역대 최고인데 월세는 안 내려가는 진짜 이유 | 월세 300만 원 빈 상가 계산서`

### 썸네일 (파일: `_thumbA/B/C.png`)
- **A안 (추천) [S1·S6]:** 3층 건물(1층 '임대' 종이, `월세 300만` 가격표) + 계산기 화면 `월세 −50만 원 / 건물값 −1억 5천` / 딱지 `수익률 4%로 건물값을 매기면 · 예시 상가` / `월세 50만 원 깎으면` / `건물값 1억 5천 증발(?)`
- B안 [S4·S2]: 크게 그린 빈 1층 가게 + '임대' 종이 + 흰 쪽지 `월세 50만 원 인하 = −1억 5천 건물값 (예시)` / 딱지 `반년째 빈 1층 · 건물주의 계산 (예시)` / `"월세 깎으면` / `건물값이 떨어져요"`
- C안 [S5]: 빈 가게 + 걱정하는 계산이 + 쪽지 `공실 6개월 −2,040만 / 월세 50만 인하 −1억 5천` / 딱지 `상가 공실률 13.7% (2026년 3분기, 부동산원)` / `비워 두는 게` / `일곱 배 싸다(?)`

### 설명
```
1층 상가 월세 300만 원. 반년째 비어 있는데 건물주는 한 푼도 깎지 않습니다.
건물주의 계산기로 두드려 보면, 월세 50만 원을 깎는 순간 사라지는 건물값은 1억 5,000만 원. 반년 비워 둔 손해 2,040만 원의 일곱 배가 넘습니다.

📌 목차
0:00 오프닝: 50만 원 = 1억 5,000만 원
0:43 예시 상가: 1층 월세 300만 원
1:15 월세 1만 원 = 건물값 300만 원
2:13 반년 비워 두는 값
3:13 석 달 공짜의 비밀
3:59 세입자 쪽 계산서
4:46 실제 숫자로 보면
5:36 숫자를 바꾸는 손잡이
6:28 상가 계약 전 숫자 5가지
7:21 마무리

📌 결과 한눈에 (예시 상가, 월세 300만 원 · 수익률 4%)
· 건물값 = 1년 월세 ÷ 수익률 = 3,600만 ÷ 0.04 = 9억 원 → 월세 만 원 한 장 = 건물값 300만 원
→ 월세 50만 원 인하 = 건물값 1억 5,000만 원 (9억 → 7억 5,000만)
→ 반년 비워 두기 = 못 받은 월세 1,800만 + 관리비·세금 240만 = 2,040만 원 (일곱 배 차이)
→ 5년 동안 깎아 준 월세 3,000만 원 = 약 9개월 공실, 건물값까지 넣으면 44개월
→ 석 달 공짜(렌트프리) = 900만 원, 계약서 월세 300만 원이라 건물값 9억 그대로. 세입자 첫해 평균 225만 원
→ 세입자 5년: 석 달 공짜 + 300만 = 1억 7,100만, 처음부터 250만 = 1억 5,000만 (2,100만 차이)
→ 수익률 3%면 50만 인하 = 2억, 5%면 1억 2,000만, 6%면 1억

📌 상가 계약 전 꼭 볼 숫자 5가지
1. 그 자리가 비어 있던 기간
2. 첫해 실제 평균 월세 (공짜 기간까지 넣어 12로 나누기)
3. 계약서에 적히는 월세 (다음 5% 인상의 바탕)
4. 관리비까지 더한 한 달 자리값
5. 10년 뒤 최대 월세 (해마다 5%씩 최대로 오르면 300만 원은 약 465만 원)
직접 해 보기: 월세 200만 원, 수익률 5%인 상가가 20만 원을 깎으면 건물값은 4,800만 원 줄어든다 (건물값 4억 8,000만 원의 10분의 1)

📌 계산 가정 (예시 가정 · 보증금·세금 제외)
- 1층 상가 월세 300만 원, 수익률(수익환원율) 4%, 제안 월세 250만 원
- 비어 있는 동안 관리비·재산세·보험료 등 한 달 40만 원
- 렌트프리 석 달, 월세 인상 없이 5년 비교
- 실제 건물값은 감정평가와 거래 사례로 정해진다. 인상 5% 상한은 법이 정한 보증금 범위 안의 상가 기준

📌 출처
- 수익환원율 4%, 월세 300만 원이면 9억, 250만 원이면 7억 5,000만 원 예시: 국민일보 2025.12.4
- 2026년 2분기 상가 공실률 13.4%(통계 작성 뒤 최고), 1층 6.7%: 한국부동산원 상업용부동산 임대동향조사, 뉴시스 2026.7.30
- 2026년 3분기 공실률 13.7%(중대형 14.7%, 소규모 8.7%), 임대가격지수 전 분기 대비 0.02% 하락: 한국부동산원, SBS Biz 2026.10.29 · 경북매일 2026.10.29
- 렌트프리로 명목상 상가 가치를 지키는 사례: 비즈한국 2019.6.7
- 공실이 생겨도 임대료를 내리는 건물주는 찾기 힘들다(공인중개업소 관계자): 조선비즈 2023.6.15
- 월 임대료 10% 인하 = 1년에 한 달 치를 조금 넘는 수입: 디지털데일리 2026.7.18
- 갱신 요구 10년, 증액 5% 상한: 상가건물 임대차보호법 제10조·제11조, 시행령 제4조
```
