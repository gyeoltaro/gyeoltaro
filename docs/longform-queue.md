# 롱폼 매일 제작 대기열

2026.11.1 대표님 결정: **롱폼 하루 한 편, 8~10분(나레이션 공백 뺀 3,000~3,500자), 매일 자동 제작.** 자동 작업은 `routines/calc-daily-longform.md` 를 따른다. 여기서 다음 편 번호·주제를 고르고, 만든 뒤 상태를 고친다.

- 다음 번호: **LF.10** (LF.01~09 완료)
- 주제를 고르는 기준: ① 공개된 원문 근거가 충분하다(숫자 3개 이상을 원문으로 확인) ② 소비자가 아는 업종·가격으로 시작한다(LF.02 치킨이 반응을 받았다) ③ 이미 만든 쇼츠 숫자와 이어진다 ④ 같은 반전을 연달아 쓰지 않는다.
- 근거가 모자라면 만들지 않고 '보류'로 적는다. 숫자를 지어내지 않는다.

- 2026.11.4 LF.09: 5순위 호프집 권리금. 권리금 통계는 재경일보 대신 대전일보 2025.2.2(한국부동산원 2024년 4분기)로 다시 확인했고, 호프주점 사업자 감소·생맥주 주세 경감 종료는 뉴스1(파이낸셜뉴스 2026.10.8) 원문으로 확인. 권리금을 '월 순이익 몇 달 치'로 부르는 관행은 근거 원문이 없어 쓰지 않았다. 다음은 6순위 탕후루(유행 수명) — 2024년 이후 폐업·인허가 추이 원문을 먼저 연다. 어제·오늘 반전(부가 매출·권리금)과 겹치지 않는다.
- 2026.11.3 LF.08: 4순위 PC방. 먹거리 비중 최신 통계는 못 찾았다(2021 34.2% 는 원문 재확인 못 함) → 한 점주 가게 60~70%(뉴스토마토 2023)를 '한 가게 사례'로만 쓰고, 이 편의 41%는 예시 가정으로 뒀다. 확인 수치는 국세통계 PC방 수·콘진원 이용률·게임 사용료 인상(바이라인). 다음은 5순위 호프집 권리금 — 주점업 폐업·권리금 회수 원문을 먼저 연다.
- 2026.11.2 LF.07: 대표님이 '14분짜리'를 직접 요청해 3순위 스터디카페를 13분대로 만들었다. 다음 자동 작업(02:37)은 4순위 PC방(8~10분 규칙)으로 간다 — 먹거리 비중 최신 자료(2021은 오래됨)를 먼저 확인.
- 2026.11.2 LF.06: 공개 피드 기준 LF.03~05 세 편 연속 0회(노출 문제로 보임). 다음은 3순위 스터디카페(건물주) — 쇼츠 EP.08 이 조회 상위였고, 반전(건물주)이 LF.06(고정비 분담·소액 주문)과 겹치지 않는다. 임대료·좌석당 수익 원문을 먼저 연다.
- 2026.11.1 LF.05: 다음 편(2순위 배달 분식)은 LF.02 치킨과 겹치지 않게 '소액 주문' 쪽으로 간다. 공개 피드 11.1 기준 LF.04 0회 — 순서는 유지.
