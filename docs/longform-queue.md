# 롱폼 매일 제작 대기열

2026.11.1 대표님 결정: **롱폼 하루 한 편, 8~10분(나레이션 공백 뺀 3,000~3,500자), 매일 자동 제작.** 자동 작업은 `routines/calc-daily-longform.md` 를 따른다. 여기서 다음 편 번호·주제를 고르고, 만든 뒤 상태를 고친다.

- 다음 번호: **LF.05** (LF.01~04 완료)
- 주제를 고르는 기준: ① 공개된 원문 근거가 충분하다(숫자 3개 이상을 원문으로 확인) ② 소비자가 아는 업종·가격으로 시작한다(LF.02 치킨이 반응을 받았다) ③ 이미 만든 쇼츠 숫자와 이어진다 ④ 같은 반전을 연달아 쓰지 않는다.
- 근거가 모자라면 만들지 않고 '보류'로 적는다. 숫자를 지어내지 않는다.
