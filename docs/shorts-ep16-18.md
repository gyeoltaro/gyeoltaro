## EP.16 1인 미용실 — 노쇼

### 제목 (2안)
- **A (추천):** `1인 미용실 예약 10건 중 1건 노쇼, 한 달 56만 원이 사라진다(?)`
- B: `월 매출 700만 원 1인 미용실, 노쇼 10%면 남는 돈은?`

### 설명
```
#노쇼 #자영업 #비밀의계산기
예약이 꽉 찬 1인 미용실, 월 매출 700만 원이면 남는 돈은 약 250만 원.
그런데 예약 열 건 중 한 건이 안 오면 매출 70만 원이 사라집니다. 월세와 할부는 그대로고 아끼는 건 재료비 14만 원뿐이라, 남는 돈은 194만 원. 한 달 56만 원, 1년이면 672만 원입니다.

📌 가정 예시 · 세금 제외: 예약 하루 8건 × 한 건 3만 5천 원 × 25일 = 월 매출 700만 원, 재료비 140만(매출의 20%), 임대료 150만, 전기·카드 수수료 60만, 의자·기계 할부 100만. 노쇼 비율 10%는 가정입니다.
📌 참고: 현대경제연구원은 2017년 보고서에서 음식점·미용실·병원·고속버스·소규모 공연장 5대 서비스업의 예약 부도 매출 손실을 연 4조 5,000억 원으로 추산했습니다 (한국경제 2024.12.6 보도 인용, 업종별 부도율은 원문에서 확인하지 못해 영상에는 쓰지 않았습니다).

🧮 비밀의 계산기 — 화려해 보이는 장사의 진짜 수익 구조를 계산기로 두드려 봅니다.
```

### 태그
```
노쇼,예약 부도,미용실 창업,1인 미용실,미용실 노쇼,예약 취소,자영업,소상공인,미용실 매출,비밀의 계산기
```

### 고정 댓글
```
예약해 놓고 못 가게 됐을 때, 미리 연락 드리시나요? 👇
사장님이시라면 노쇼, 어떻게 대처하시는지도 궁금합니다.
```

## EP.17 동네 피자집 — 할인의 함정

### 제목 (2안)
- **A (추천):** `피자 20% 할인하면 3배 팔아야 본전(?) 한 판 6,000원이 2,000원으로`
- B: `월 매출 2,000만 원 동네 피자집, 20% 할인하면 남는 돈은?`

### 설명
```
#피자 #자영업 #비밀의계산기
한 판 2만 원 동네 피자집, 한 달 천 판이면 매출 2,000만 원에 남는 돈은 약 150만 원.
그런데 20% 할인을 하면 한 판에 남는 돈이 6,000원에서 2,000원으로 3분의 1이 됩니다. 주문이 두 배로 늘어도 한 달 50만 원 적자, 원래 150만 원을 벌려면 천 판이 아니라 삼천 판, 하루 100판을 팔아야 합니다.

📌 가정 예시 · 세금 제외: 한 판 2만 원, 재료·포장·카드 수수료 70%(한 판 1만 4천 원), 월 천 판. 임대료 200만, 알바 1명 200만, 전기·가스 50만. 주문이 늘어도 고정비는 그대로라고 가정했습니다(실제로는 늘어난 주문을 감당할 인력이 더 필요할 수 있습니다).
📌 계산: 남는 돈 비율 30%에서 20%를 깎으면 한 판 이익 6,000원 → 2,000원, 같은 이익을 내려면 30 ÷ (30 − 20) = 3배.

🧮 비밀의 계산기 — 화려해 보이는 장사의 진짜 수익 구조를 계산기로 두드려 봅니다.
```

### 태그
```
피자집 창업,동네 피자집,피자 할인,할인 이벤트,마진율,손익분기,자영업,소상공인,사장님,비밀의 계산기
```

### 고정 댓글
```
사장님이라면 20% 할인, 해 보신 적 있나요? 결과가 어땠는지 알려 주세요 👇
손님이라면 할인 때 시키는 편인가요?
```

## EP.18 필라테스 — 선결제 착시

### 제목 (2안)
- **A (추천):** `필라테스 30회권 2,700만 원 입금, 이번 달 진짜 번 돈은 720만 원(?)`
- B: `필라테스 통장에 1,700만 원 남았는데, 실제 계산은 280만 원 적자?`

### 설명
```
#필라테스 #자영업 #비밀의계산기
필라테스 30회권 90만 원, 신규 회원 30명이 결제하면 통장에 2,700만 원이 들어옵니다. 비용 1,000만 원을 빼면 통장에는 1,700만 원이 남죠.
하지만 이번 달 수업은 한 명당 8회, 실제로 번 돈은 720만 원. 나머지 1,980만 원은 앞으로 해 줘야 할 수업값입니다. 번 돈 기준으로 보면 280만 원 적자. 받은 돈을 미리 써 버리면 남은 수업을 할 돈이 없습니다.

📌 가정 예시 · 세금 제외: 30회권 90만 원(회당 3만 원) × 신규 30명, 이번 달 수업 한 명당 8회, 강사 급여 450만, 임대료 300만, 기구 할부 150만, 전기·카드 수수료 100만. 신규 회원이 몰린 달을 가정한 예시이며 모든 스튜디오가 그렇다는 뜻이 아닙니다.
📌 출처: 폐업 관련 선불거래 피해구제 접수 2021년 37건 → 2024년 264건, 최근 5년 누적 838건 중 필라테스 325건(38.8%)·헬스장 291건(34.7%) (한국소비자원 자료, 박성훈 의원실 · SBS Biz 2026.9.26)

🧮 비밀의 계산기 — 화려해 보이는 장사의 진짜 수익 구조를 계산기로 두드려 봅니다.
```

### 태그
```
필라테스,필라테스 창업,선결제,선불거래,회원권,헬스장 선결제,자영업,소상공인,소비자원,비밀의 계산기
```

### 고정 댓글
