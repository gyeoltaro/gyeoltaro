- 첫 30초: "붕어빵 세 마리 2,000원 · 팥값 평년보다 43.6%(숫자 훅) → 한 마리에 팥값 더 드는 돈 20원(첫 답, 약 0:08) → 그런데 값은 2개 1,000 → 3개 2,000, 한 번에 33% → 그래도 두 사람 시급 6,000원 → 1,000원으로 올리면 열 명 중 네 명이 떠나도 몫은 그대로, 그런데도 못 올린다".
- 중심 그림: 한 봉지(세 마리) 2,000원 = **100원 동전 20개**. 반죽 3 · 팥 앙금 2 · 가스·봉투 2 · 자리·전기 1 · 두 사람 몫 12. 계단 그림: 한 마리 값 333 → 500 → 667 → 1,000원.
- **노점 운영 숫자는 전부 예시 가정이다.** 부부 두 사람, 하루 10시간 × 25일, 하루 100봉지(300마리), 앙금 한 마리 25g, 가스 일주일 두 통, 자리·전기·틀 수리 월 25만, 3년 비용 690 → 745 → 800원, 장사 다섯 달(11~3월). 반죽·앙금·봉투 단가는 2025년 르포의 한 노점 값이다.

## 계산표 (예시 노점 · 세금 제외 · 전부 python3 로 다시 계산)
노점: 하루 100봉지 × 25일 = 2,500봉지(7,500마리). 3개 2,000원 → 매출 500만 원. 두 사람 × 하루 10시간 × 25일 = 500시간.

| 항목 | 가정 | 한 달 | 2,000원 중 | 근거 |
|---|---|---|---|---|
| 반죽 | 5kg 1만 원 → 100마리 = 한 마리 100원 | 75만 | 300 (동전 3) | 헤럴드경제 2025.11.25 르포 (한 노점) |
| 팥 앙금 | 3kg 8,000원, 한 마리 25g → 120마리 = 66.7원 | 50만 | 200 (동전 2) | 앙금 값: 같은 르포 · 25g 은 예시 |
| 가스 | 20kg 56,240원 × 주 2통 × 4주 = 44만 9,920원 | 45만 | 180 | 한 통 값: 한국경제 2026.11.4 (오피넷 kg당 2,812원 × 20) · 주 2통: 르포 노점 · 예시 |
| 봉투 | 1,000장 2만 원 = 장당 20원 | 5만 | 20 | 르포 |
| 자리·전기·틀 수리 | | 25만 | 100 (동전 1) | 예시 |
| 두 사람 몫 | | **300만** | **1,200 (동전 12)** | |

→ 두 사람 × 하루 10시간 × 25일이면 시급 6,000원, 최저시급 1만 320원의 58%

📌 붕어빵 값을 정하기 전 꼭 볼 숫자 5가지
1. 한 봉지 재료비 (반죽 + 앙금 + 봉투)
2. 한 달 고정비 (가스 통 수 + 자리값 + 전기)
3. 두 사람 시급 (한 달 몫 ÷ 둘이 일한 시간)
4. 한 계단의 무게 (다음 값으로 올리면 손님이 몇 명까지 떠나도 되나)
5. 장사하는 달 수 (겨울 몫 ÷ 12달)
직접 해 보기: 3개 2,000원, 하루 80봉지, 25일, 재료·봉투 600원, 고정비 60만 → 280만 − 60만 = 220만 원

📌 계산 가정 (예시 가정 · 세금 제외)
