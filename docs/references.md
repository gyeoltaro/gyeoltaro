# 참고 영상 분석

남의 잘 된 쇼츠를 뜯어보고, 우리 채널에 옮길 수 있는 것만 적는다. 수치는 분석한 날 기준이다.

## 법의 허점(?)을 노린 천재 건축가의 아파트 — @세상에이런곳이 (2026.10.27 분석)
https://www.youtube.com/shorts/RmHTf-usam8

- 2025.7.18 업로드, 42초, 조회 1,004만 · 좋아요 8.2만(0.8%) · 댓글 약 1,000. 채널 구독자 6,630명, 쇼츠 41편 누적 조회 약 4,600만.
- 채널 100만+ 9편은 모두 39~58초(1분 미만)이고 첫 6주(2025.7~8)에 몰려 있다. 최근 자연·풍경 주제는 6천~3만 회.
- 잘 된 제목 = 사람·결정 + 규칙·돈·실수의 갈등 + 결과: "법의 허점(?)을 노린 천재 건축가", "빌딩 붕괴를 막아낸 한 대학생의 질문", "버블 경제가 낳은 '반쪽짜리' 건물". 안 된 제목 = 예쁘다·신기하다만 있는 것: "CG처럼 보인다는 유리 건물의 정체", "파란 용암이 흐른다는 화산의 정체".

**대본 구조 (자동 자막 기준, 공백 뺀 309자 = 초당 7.4자)**

| 시각 | 역할 | 대사 |
|---|---|---|
| 0~3초 | 제목을 그대로 읽는 훅 + 대상 | 법의 허점을 노린 천재 건축가의 아파트. 캐나다 밴쿠버 하우스. |
| 3~9초 | 눈에 보이는 이상한 점 + **떡밥** | 아랫부분이 더 얇은 독특한 모양인데, 이렇게 지을 수밖에 없었던 이유가 있었어. |
| 9~20초 | 제약 두 개 | 다리에서 30m 떨어져야 한다는 규정 + 쓸모없는 삼각형 땅 |
| 20초 | **중간 질문(재훅)** | 이런 땅에 대체 뭘 지어야 하지? |
| 21~33초 | 주인공의 발견 = 반전 | 법 조항을 다시 읽어 보니, 30m만 떨어뜨리면 위로는 튀어나와도 된다 |
| 33~42초 | 결과, 바로 끝 | 아래는 얇게, 위는 정상으로 → 지금은 랜드마크가 됐다고 |

**화면**
- 위쪽 검은 띠에 제목 두 줄(흰색 + 노랑)이 영상 내내 고정된다. 중간부터 들어온 시청자도 훅을 본다. 첫 프레임이 곧 썸네일이다.
- 가운데에 실제 사진(CC 라이선스, 확대·크롭), 아래쪽에 검은 상자 + 흰 글씨 자막.
- 엔딩 카드가 없다. 마지막 단어에서 끊겨 처음으로 바로 반복 재생된다.

**반응**
- 다시 본 구간 그래프는 처음 2초에 크게 떨어진 뒤 끝까지 고르게 줄어든다. 튀는 구간은 없다(상대값이라 실제 지속률은 아님).
- 댓글은 "허점이 아니라 법이 허용한 최대 범위다" 같은 반박, 안전·누수·일조량 걱정이 많다. 제목의 "(?)" 가 단정을 피하면서 논쟁을 부른다.

**우리 채널에 옮긴 것 → 포맷 v2 (EP.07부터 적용)**
1. 첫 8초 안에 반전 예고: "그런데 진짜 돈 버는 사람은 따로 있죠."
2. 결과 직전에 질문 한 줄: "한 잔 팔면 얼마나 남을까요?"
3. 위쪽 제목 띠: 훅 제목 두 줄 + 가정 고지문을 영상 내내 고정.
4. 엔딩 카드 없음: 마지막 단어 0.6초 뒤 끝 → 바로 반복 재생.
5. 제목은 "누가·무슨 꾀/실수로·얼마를" 꼴, 단정이 애매하면 "(?)".

## 인테리어 5,500만 원 → 2,600만 원 — @jangsahero 장사히어로 (2026.10.27 분석)
https://www.youtube.com/shorts/9lmYP7f9s2k

- 54초, 분석 시점 조회 7회(막 올라온 영상이라 성과는 판단 불가). 한 프랜차이즈 본사 채널로, 쇼츠는 대개 1천~3천 회. 가장 잘 된 편이 "프랜차이즈 원가가 달랐던 이유"(3천), "쌀국수 무한으로 줘도 수익률이 좋은 이유"(2천) → 업계에서도 '원가·수익 구조'가 제일 먹힌다.
- 대본(343자, 초당 6.4자): 0초 숫자 훅 "견적 5,500만 원 → 2,600만 원" → 5초 "어떻게 절반 넘게 줄였을까요?" → 방법 나열(구조 살리기, 페인트, 소파 연장, 필름, 액자) → 29초 "비용만 줄이면 끝일까요?" → 바 테이블·메뉴 노출 → 41~52초 교훈 정리.
- 화면(유튜브가 고른 한 장면 기준): 밝은 배경의 AI 3D 아이소메트릭 매장, 흰 테두리 큰 숫자 "5,500 → 2,600", 상자 없는 흰 자막.

**배울 점:** 숫자 훅과 5초 질문은 참고 영상 1과 같은 공식이다.
**아쉬운 점 (우리가 피할 것):**
- 훅의 2,900만 원 차이를 끝까지 쪼개 보여주지 않는다. 방법마다 "이걸로 얼마"가 없다.
- 제목은 '투자금 회수'인데 회수 기간 계산이 영상에 없다. 제목과 내용이 어긋난다.
- 마지막 11초가 교훈 정리라 늘어진다. 결론 한 줄로 끝내야 한다.
- "실제 사례"라면서 화면은 AI 렌더라 믿음이 약하다. 사례라면 실제 전후 사진이 낫다.

## "S&P500 ETF 이만큼 사두세요" — @경제학똑똑 (롱폼, 2026.10.27 분석)
https://www.youtube.com/watch?v=6VeN3G_okwI

- 14분 35초, 조회 117만, 댓글 879. 얼굴 없는 내레이션 채널. 고정 댓글은 '이런 유튜브 만드는 법' 강의 홍보.
- 썸네일: 마스코트 캐릭터(정장 입은 동그란 얼굴, 돈다발) + 세 줄 세 색 문구 "노후 걱정 끝! / S&P500 / 이만큼 사두세요".
- 구성(5,651자): 0~1분 "이 영상 하나만 보세요" 약속 + 예금 금리 vs 물가 → 1~2.5분 개념(어벤져스 500명) → 2.5~4분 버핏 유언·10년 내기 → 4~6분 장점 다섯 가지를 숫자로 → 6~9분 브랜드 비교를 '아이스 아메리카노' 비유로 → 9~13분 국내 vs 해외 ETF, 세 기준 비교 → 13~14.5분 행동 촉구.
- **다시 많이 본 구간**(상대값): 4:20~4:40 "1억 → 예금 1.8억 vs S&P 7억, 차이 5억" / 7:10~7:35 타이거·코덱스·SPY·VOO 구분 / 11:05~12:40 ISA 세금 계산(77만 → 29.7만 원)과 최종 결론(최고점 12:24). 도입 1분은 거의 안 다시 본다.
- 댓글: "제일 알아듣기 쉬운 설명" 칭찬이 대부분, "ISA·연금저축 더 자세히" 요청 → 후속 영상으로 이어짐.
- 사실 관리 허점: 금리·물가를 설명란 3.5%/3.6%, 도입부 2.5%/2.3%, 중간 3%로 서로 다르게 말한다. TIGER 미국S&P500 보수 0.07%는 2025.2.6 0.0068%로 인하된 뒤라 낡은 수치다. 제목의 '이만큼'에 대한 답(얼마나)이 영상에 없다.

**우리 롱폼에 옮길 것**
1. 사람들이 다시 보는 곳은 '내 돈으로 계산한 숫자'와 '그래서 뭘 하면 되나'다 → 롱폼도 계산기 장면이 중심.
2. 어려운 개념은 생활 비유 하나로 끝까지 끌고 간다(아메리카노 = ETF).
3. 장마다 "그럼 여기서 질문이 생깁니다"로 다음 장을 예고한다.
4. 썸네일은 고정 마스코트 + 세 줄 문구. 우리는 계산기 캐릭터를 만든다.
5. 피할 것: 숫자 불일치·낡은 수치, 제목이 약속한 답을 안 주는 것, 1분짜리 도입 약속.
