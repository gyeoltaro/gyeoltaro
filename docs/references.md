## 법의 허점(?)을 노린 천재 건축가의 아파트 — @세상에이런곳이 (2026.10.27 분석)

- 잘 된 제목 = 사람·결정 + 규칙·돈·실수의 갈등 + 결과: "법의 허점(?)을 노린 천재 건축가", "빌딩 붕괴를 막아낸 한 대학생의 질문", "버블 경제가 낳은 '반쪽짜리' 건물". 안 된 제목 = 예쁘다·신기하다만 있는 것: "CG처럼 보인다는 유리 건물의 정체", "파란 용암이 흐른다는 화산의 정체".

**대본 구조 (자동 자막 기준, 공백 뺀 309자 = 초당 7.4자)**

| 시각 | 역할 | 대사 |
|---|---|---|
| 0~3초 | 제목을 그대로 읽는 훅 + 대상 | 법의 허점을 노린 천재 건축가의 아파트. 캐나다 밴쿠버 하우스. |
| 3~9초 | 눈에 보이는 이상한 점 + **떡밥** | 아랫부분이 더 얇은 독특한 모양인데, 이렇게 지을 수밖에 없었던 이유가 있었어. |
| 9~20초 | 제약 두 개 | 다리에서 30m 떨어져야 한다는 규정 + 쓸모없는 삼각형 땅 |

| 21~33초 | 주인공의 발견 = 반전 | 법 조항을 다시 읽어 보니, 30m만 떨어뜨리면 위로는 튀어나와도 된다 |
| 33~42초 | 결과, 바로 끝 | 아래는 얇게, 위는 정상으로 → 지금은 랜드마크가 됐다고 |

**화면**
- 위쪽 검은 띠에 제목 두 줄(흰색 + 노랑)이 영상 내내 고정된다. 중간부터 들어온 시청자도 훅을 본다. 첫 프레임이 곧 썸네일이다.
- 가운데에 실제 사진(CC 라이선스, 확대·크롭), 아래쪽에 검은 상자 + 흰 글씨 자막.
- 엔딩 카드가 없다. 마지막 단어에서 끊겨 처음으로 바로 반복 재생된다.

**반응**
- 다시 본 구간 그래프는 처음 2초에 크게 떨어진 뒤 끝까지 고르게 줄어든다. 튀는 구간은 없다(상대값이라 실제 지속률은 아님).
- 댓글은 "허점이 아니라 법이 허용한 최대 범위다" 같은 반박, 안전·누수·일조량 걱정이 많다. 제목의 "(?)" 가 단정을 피하면서 논쟁을 부른다.

**우리 채널에 옮긴 것 → 포맷 v2 (EP.07부터 적용)**
1. 첫 8초 안에 반전 예고: "그런데 진짜 돈 버는 사람은 따로 있죠."
2. 결과 직전에 질문 한 줄: "한 잔 팔면 얼마나 남을까요?"
3. 위쪽 제목 띠: 훅 제목 두 줄 + 가정 고지문을 영상 내내 고정.
4. 엔딩 카드 없음: 마지막 단어 0.6초 뒤 끝 → 바로 반복 재생.
5. 제목은 "누가·무슨 꾀/실수로·얼마를" 꼴, 단정이 애매하면 "(?)".

**배울 점:** 숫자 훅과 5초 질문은 참고 영상 1과 같은 공식이다.

- "실제 사례"라면서 화면은 AI 렌더라 믿음이 약하다. 사례라면 실제 전후 사진이 낫다.

**대본 공통 뼈대**
1. 0:00 구체적 장면·숫자: "매달 30만 원 넣는 분, 계좌 열었다가 조용히 닫은 적", "같은 S&P500 산 두 사람, 세금 970만 vs 3,700만".

3. 0:45 "좋아요, 구독, 알림 설정 꾹 눌러 주세요" (전 편 같은 문장).
4. 1~2분 비유로 정의 (바닥에 샘이 달린 양동이 = 복리).
5. 2분 안팎 **첫 계산 답** ("월 50만 원, 연 7% → 8,651만 원, 10년 1개월").
6. 중반 "1만 달러 기준으로 계산해 보겠습니다"처럼 시청자 돈으로 환산. 번호 매긴 단락.

9. 끝: 한 문장 정리 → 댓글 질문("시작점까지 몇 년 남으셨나요?") → 다음 영상 예고 → 채널 인사("우리 모두 보물섬을 향해").

**다시 많이 본 구간**(상대값)은 모든 편에서 첫 계산 답, 반전, 체크리스트였다. 도입 1분은 거의 안 다시 본다. 국민성장펀드 편 댓글에 "13:51 여기부터"가 달렸다 → 설명란에 챕터(타임스탬프)가 없다.

**썸네일 공식:** 아래쪽 두 줄(흰 줄 + 노랑·초록 강조 줄, 굵은 검은 테두리), 큰 숫자 대비("1560원 > 1370원", "같은 3000만원"), 'vs' 좌우 대결, '이것·이런 일' 숨김, 흰 동그란 얼굴 마스코트(경제학 똑똑과 같은 화풍) 또는 사실적 AI 장면.

**설명란:** "📌 이 영상에서 다루는 내용" 목록이 대본 단락과 같다 + 면책 문구 + 태그 12개.

**우리 채널에 옮길 것**
1. "같은 돈, 다른 결과" 비교가 우리 계산기 정체성과 똑같다: "같은 1억으로 창업, 5년 뒤 손에 쥐는 돈".
2. 제목은 결과 숫자 차이를 보여주고 원인은 숨긴다. 선택지 이름만 나열하지 않는다.
3. 롱폼은 2분 안에 첫 계산 답, 중반 반전, 끝에 체크리스트. 설명란에 챕터를 단다.
4. 시사 숫자(최저시급 발표, 배달 수수료 개편 등)가 나오면 바로 계산해서 올린다.
5. 피할 것: 확정 안 된 제도, 절차 안내, 수치 오류. 같은 화풍·같은 문장을 매일 찍어내는 방식은 '오리지널 우선' 흐름에서 위험하다.
