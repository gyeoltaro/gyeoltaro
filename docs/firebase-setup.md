# 서버(Firebase) 연결하기

> 관장님께 드릴 설명은 화면 사진이 들어간 **사용설명서**(https://awoolimtkd.github.io/manual.html, 원본 `www/manual.html`)가 최신입니다. 이 문서는 같은 내용을 개발자 기준으로 정리한 것입니다.

관장님이 한 번만 하시면 되는 준비입니다. 컴퓨터로 하시는 게 편하고, 15분 정도 걸립니다.
화면 이름은 Firebase가 바꿀 때가 있어서 조금 다를 수 있어요.

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 들어갑니다.
2. **프로젝트 추가** → 이름(예: `우리태권도-관리`)을 넣습니다.
3. "Google 애널리틱스"는 **사용 안 함**으로 둡니다. 쓰지 않는 정보를 모으지 않기 위해서예요.
4. **프로젝트 만들기**를 누릅니다.

요금제는 처음 그대로 **Spark(무료)** 로 둡니다. 원생 100명 규모는 무료 한도 안에서 충분히 쓸 수 있어요.
(나중에 앱 푸시를 붙일 때만 Blaze 요금제로 바꾸고, 그때 예산 알림을 같이 설정합니다.)

## 2. 로그인 방식 켜기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭에서 두 가지를 켭니다.
   - **이메일/비밀번호**: 관장·사범님 로그인용
   - **익명**: 학부모 기기 연결용 (학부모 이름·전화번호는 여기에 저장되지 않아요)

## 3. 데이터베이스 만들기 (서울)

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치를 **asia-northeast3 (Seoul)** 로 고릅니다. ⚠️ **나중에 바꿀 수 없으니 꼭 서울로** 골라 주세요.
3. **프로덕션 모드에서 시작**을 고르고 만들기를 누릅니다. (처음에는 아무도 못 읽게 잠겨 있다가, 6번에서 보안 규칙을 붙여요.)

## 4. 웹 앱 등록하고 설정값 받기

1. 왼쪽 위 톱니바퀴 → **프로젝트 설정 → 일반**.
2. 아래쪽 **내 앱**에서 웹 아이콘(`</>`)을 누르고, 앱 이름(예: `태권도 관리`)을 넣고 **앱 등록**.
3. 화면에 나오는 `firebaseConfig = { ... }` 내용을 복사해 둡니다.
   - 앱 시작 화면(또는 설정)의 **우리 도장 서버 연결**에 붙여 넣으면 그 기기가 이 서버에 연결됩니다. 코드에 넣을 필요는 없어요.
   - 이 값은 비밀번호가 아니라 "어느 프로젝트를 쓰는지" 알려 주는 주소라서 연결 링크·초대 문자에 들어가도 괜찮아요. 실제 보호는 보안 규칙이 합니다.

## 5. 데이터 처리 약관 동의 (개인정보 처리 위탁 계약)

**프로젝트 설정** 화면에서 **데이터 처리 및 보안 약관(Data Processing and Security Terms)** 항목을 찾아 읽고 동의합니다.
개인정보 보호법이 요구하는 "위탁 계약을 문서로 남기기"를 이 동의로 갈음합니다. 앱의 개인정보 처리방침에는 이미 위탁 내용이 들어 있어요.

## 6. 앱에서 관리자 계정 만들고 보안 규칙 붙이기

앱 주소 **https://awoolimtkd.github.io** 를 열고, 시작 화면의 **우리 도장 서버 연결**에 4번의 설정값을 붙여 넣은 뒤:

1. **관장 · 사범님** → **처음이에요 · 관리자 계정 만들기** → 이메일과 비밀번호(6자 이상)를 정합니다.
2. 메일함에 온 **인증 메일의 링크**를 누르고, 앱에서 **인증 확인**을 누릅니다.
3. 앱이 **서버 보안 규칙 붙이기** 화면을 보여 줍니다. 관장님 이메일이 이미 들어 있어요.
   - **규칙 복사** → Firebase 콘솔 **Firestore Database → 규칙** 탭 → 있던 내용을 모두 지우고 붙여 넣기 → **게시**.
   - 1분쯤 뒤 앱에서 **다시 확인**을 누릅니다.
4. **서버 처음 설정**에서 시작 방법을 고릅니다.
   - 이 기기에 1단계 자료가 있으면 **이 기기의 자료 올리기**
   - 처음이면 **빈 상태로 시작**

## 7. 도장 태블릿 연결

관장님 기기의 **설정 → 서버 · 관리자 계정 → 다른 기기 연결 링크**를 태블릿(공기계)에 보내 열고, **출석체크** → 관장님 계정으로 로그인하면 출석 화면이 켜집니다.
인터넷이 잠깐 끊겨도 출석은 기록되고, 다시 연결되면 자동으로 서버에 올라가요.

## 8. 사범님 계정 추가 (선택)

**설정 → 서버 · 관리자 계정**에서 사범님 이메일을 추가하면 새 보안 규칙이 나옵니다.
그 규칙을 6-3처럼 다시 붙여 넣은 뒤, 사범님이 앱에서 같은 방법으로 계정을 만들면 됩니다.

## 9. 학부모 초대

1. **원생** → 아이 선택 → **학부모 앱: 초대 코드 보내기**.
2. **문자로 보내기**를 누르면 관장님 휴대폰 문자 앱이 열립니다. 코드는 7일 동안 한 번만 쓸 수 있고, 형제·자매는 한 코드로 함께 연결돼요.
3. 어머님이 문자의 링크를 열고 **연결하기 → 전자 동의서 작성**을 마치면 연결됩니다(링크에 도장 서버와 코드가 들어 있어요).
4. 앱으로 동의한 보호자에게는 관리자 홈의 **확인 문자**로 동의 확인 문자를 보내 주세요(만 14세 미만 법정대리인 확인).

연결을 끊으려면 원생 정보의 **연결 끊기**를 누르세요. 그 기기에서는 바로 학부모 화면이 닫힙니다.

## 10. 앱 푸시 (선택)

1. Firebase 콘솔 → **업그레이드** → Blaze 요금제, 예산 알림(예: 월 1,000원).
2. 저장소에서 `npm run deploy:push -- --project 프로젝트ID` (처음엔 `npx firebase-tools login`). 함수 4개가 서울(asia-northeast3)에 올라갑니다.
3. 앱 **설정 → 앱 푸시 알림 → 앱 푸시 사용**을 켭니다. 학부모 앱 홈에 "알림 켜기"가 나타납니다.
4. 웹 푸시 인증서 키 쌍은 선택입니다(비워 두면 Firebase 기본 키).

|---|---|
