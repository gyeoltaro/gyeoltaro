**지금까지 읽히는 것 (가설):**
1. 잘된 편은 모두 **손님이 직접 쓰는 업종**(당구장·커피·택시·PC방·미용실)이다. 업주용 업종(공부방·세탁점·필라테스)은 낮다.
2. 잘된 제목은 **"○○할수록 손해 / 팔 때마다 손해 / 진짜 버는 사람은 따로"** 처럼 상식과 거꾸로 가는 한 줄(T6·T7)이다. 통계 숫자(사업자 수·점포 수·성장률)로 여는 롱폼 제목은 안 됐다.
3. 금액이 없는 제목(사진관)은 꼴찌였다 → 제목에 금액 하나는 꼭 넣는다.
4. 롱폼은 PC방 한 편만 터졌다. 한 편이라 아직 공식으로 굳히지 않는다. 시급형(LF.14 '사장님 시급은 4,615원', LF.15 '두 사람 시급은 6,000원')은 결과를 보고 적는다.
5. **(11.11 추가) 롱폼은 제목 꼴만으로는 안 뜬다:** T6 역설 + 금액을 그대로 쓴 LF.12 무한리필도 3일째 4회, T2 모순(LF.11)도 4회. 롱폼 11편 중 100회를 넘은 건 PC방(쇼츠 EP.12 와 같은 주제)·배달 분식(쇼츠 EP.10)·탕후루(82, 쇼츠 EP.06) — **쇼츠로 먼저 다룬 업종**이다. 제목보다 '쇼츠에서 검증된 업종인가'가 먼저일 수 있다(가설). 쇼츠는 11.1 뒤로 새 편이 공개 피드에 없다.

6. **(11.16 추가) LF.16~19 네 편이 공개 1~4일째 모두 0회**다. 같은 시기 LF.11~15 는 첫날부터 1~7회였다. 제목 꼴(T6·T4·T1)이 서로 다른데 똑같이 0이라 꼴 탓으로 보기 어렵다 — 노출 자체가 막혔는지(스튜디오 노출수·공개 상태) 먼저 본다(대표님 확인 필요). 쇼츠 1위 업종 당구장(LF.19)도 첫날 0. 비교: 외부 세 편(11.16)은 제목이 **질문 하나로 끝나고 답 숫자가 없다** — 우리 최근 제목은 답 숫자를 다 넣는다(가설).
