# 제목·썸네일 플레이북

매일 공부(05:49)가 이 파일을 갱신하고, 쇼츠 묶음과 롱폼(02:37)은 제목과 썸네일을 만들기 **전에** 이 파일을 읽는다.
날마다 쓰는 분석은 `docs/references.md` '## 매일 공부' 에 적는다. 이 파일에는 거기서 나온 **꼴(패턴)**, 꼴마다 본 횟수, 우리 채널 성적만 모은다.

- 꼴 이름은 `T1`(제목)·`S1`(썸네일)처럼 번호로 부른다. 업로드 문구의 제목안·썸네일안마다 어느 꼴인지 적는다(예: `제목 A안 [T6]`).
- **확인 횟수**는 이 꼴을 쓴 영상이 매일 공부에서 배수 큰 3편에 든 날의 수다. 같은 날 여러 편이 써도 1로 센다.
- **우리 성적**은 공개 피드 조회수로만 적는다(스튜디오 클릭률이 오면 같이 적는다). 숫자가 작을 땐(편당 1,000회 안쪽) 전부 가설이다.
