# 쇼츠 주제 후보

CLAUDE.md 반전 목록(유통 마진·감가상각·회전율·점주 시급·안 오는 회원·계절성·유행 수명·공급 마진·건물주·상권 포화·플랫폼 수수료·폐기 재고·미끼 상품)과 겹치지 않게 적는다. 숫자는 확인 전까지 '예시'.

## 2026.10.27
1. **당구장 — 시간대 편중 (공실 시간이 비용)**
   - 반전: 하루 24시간 중 손님이 몰리는 시간은 저녁 몇 시간뿐, 나머지 시간도 임대·전기는 똑같이 나간다. 월 매출 1,000만 원이라도 시간당으로 쪼개면 비는 시간이 월세를 먹는다.
   - 숫자 근거: 월 1,000만 원은 '월 1,000만 원 번다던 당구장' 영상 제목(수익구조 연구소, 2026.10 조회 29.9만)의 표현일 뿐 원가는 미확인. 테이블 수·시간당 요금·가동률은 **예시**. 먼저 공식 통계(당구장 평균 매출) 원문 확인 필요.
2. **무인 세탁점 — 설비 교체 주기 (수리·교체비가 숨은 비용)**
   - 반전: 매출은 안정적이지만 세탁기·건조기가 몇 년 뒤 한꺼번에 고장·교체 시기를 맞아 쌓아 둔 돈이 사라진다(감가상각 착시와 달리 '현금 목돈 지출 시점'에 초점).
   - 숫자 근거: 장비 가격·수명·월 매출 모두 **예시**. 업계 보도(무인 세탁 창업 비용)·공정위 가맹정보 확인 전에는 단정 금지.
3. **마라탕 — 손님이 담는 무게가 원가를 정한다 (객단가 편차)**
   - 반전: 무게 과금이라 같은 손님 수라도 재료를 많이 담는 손님이 늘면 원가율이 올라가는 구조. 평균 주문 무게 한 값으로 계산하면 틀린다(헤비 고객 비중 시나리오).
   - 숫자 근거: 마라탕 '평균 주문 무게'는 근거 미확보(docs/episodes.md 다음 후보 메모와 동일). 100g당 가격·원가·평균 무게는 **예시**. 출처 확보 전까지 제작 보류.

## 2026.10.28
1. **개인택시 — 기회비용 (번호판 값에 붙는 이자)**
   - 반전: 하루 벌이는 남아 보이지만, 번호판 1억 원을 예금·대출 이자로 바꾸면 매달 그만큼이 '보이지 않는 비용'이다. 감가상각과 달리 번호판은 닳지 않는다 — 문제는 묶인 돈이 낳지 못한 이자.
   - 숫자 근거: 서울 면허 시세 약 1억 1,450만~1억 1,550만 원(2026.3~5, 중개업체·운수면허협회 표시 — 비공식 시세), 지역 차이 큼(대구 약 6,300만 원 보도). 양수교육비 52만 원(블로그 표기, 미확인). 금리·월 매출·연료비는 **예시**. 시세는 정부 고시가 아니므로 "예시 시세"로 표시.
2. **무인 문구·과자점 — 도난 손실 (보이지 않는 손님)**
   - 반전: 인건비 0원이 장점인데, 계산 안 하고 가져가는 손실이 마진을 갉아먹는다. "몇 개 없어지는지"가 순이익을 가른다(폐기 재고와 달리 '팔린 줄 알았던 물건').
   - 숫자 근거: 경찰청 무인점포 절도 발생 2021년 3,514건(3~12월 집계) → 2022년 6,018건 → 2023년 10,847건(경북매일 2025.3.19 원문 확인). 일부 보도는 다른 집계(698건·1,363건)를 써서 기준이 다르다 → 영상엔 2022→2023 증가만 쓴다. 점포당 손실률·마진은 **예시**.
3. **동네 호프집 — 권리금 (나갈 때 돌려받지 못하는 돈)**
   - 반전: 들어올 때 낸 권리금은 장사가 안되면 나갈 때 못 받는다. 월 순이익이 나도 권리금을 다 잃으면 몇 년 장사가 0원이 된다(유행 수명과 달리 '자리값'의 회수 문제).
   - 숫자 근거: 한국부동산원 상업용부동산 임대동향조사 — 전국 평균 권리금 3,443만 원, 권리금 있는 상가 56.47%(2024.6.30 기준, 재경일보 2025.1.31 원문 확인). 서울 4,915만 원은 검색 요약에만 있어 미확인. 업종(주점)별 권리금·월 순이익은 **예시**. 한국부동산원 원문 보도자료 확인 후 제작.

## 2026.10.29
1. **동네 카페 — 알바 시급의 착시 (주휴수당)**
   - 반전: 시급 10,320원으로 계산하면 인건비가 맞아 보이지만, 주 15시간 이상 일하면 주휴수당이 붙어 실제 인건비는 시간당 약 1.2배다. '점주 시급'(EP.03, 사장 자신의 시급)과 달리 **직원 인건비를 잘못 잡는 실수**에 초점.
   - 숫자 근거: 2026 최저시급 10,320원(CLAUDE.md). 월 환산 209시간(주 40시간 + 주휴 8시간) × 10,320원 = 2,156,880원(민간 급여 안내 여러 곳이 일치, 고용노동부 고시 원문은 미확인 — 제작 전 확인). 카페 매출·알바 시간은 **예시**. 주휴 피하려는 '15시간 미만 쪼개기'는 다루지 않는다(편법 권장 금지).
2. **1인 미용실 — 노쇼 (빈 의자도 월세를 낸다)**
   - 반전: 예약표는 꽉 차 보이지만 예약한 손님 일부가 안 온다. 1인 매장은 그 시간을 다른 손님으로 못 채워 그대로 손실이다.
   - 숫자 근거: 현대경제연구원(2017) 5대 서비스업 예약부도 매출 손실 연 4.5조 원, 미용실 예약부도율 15%(음식점 20%) — SBS Biz 2024.12.3 원문 확인(2017년 추정치라 '예전 조사'로 표시). 공정위가 2025.10.22 음식점 단체예약 노쇼 위약금 상한을 10% → 최대 40%로 행정예고(파이낸셜뉴스 2025.10.23 원문, 시행 여부·미용실 적용은 미확인). 시술 단가·하루 예약 수는 **예시**.
3. **동네 백반집 — 티 안 나는 작은 고정비 (월 3만 원 열 개)**
   - 반전: 큰 비용(재료·월세)만 보면 남는데, 생수·렌탈·카드 단말기·앱 구독 같은 월 몇만 원짜리가 모이면 1년에 수백만 원이다. 폐기 재고(물건이 버려짐)와 달리 **매달 자동 이체로 새는 돈**.
   - 숫자 근거: '생수 월 50만 원 → 1년 564만 원 절약 vs 정수기 월 3만 원'은 동네장사 생존노트 썸네일 수치(유튜버 주장, 미검증). 항목별 금액은 전부 **예시**. 상표·실존 렌탈 업체명은 쓰지 않는다.
