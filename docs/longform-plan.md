# 롱폼 계획 — 주간 계산서

작성 2026.10.27 · 상태: **1편(LF.01) 제작 완료** → `docs/longform-ep01.md`

## 1. 왜 지금 롱폼인가
- **수익 조건:** 지금 YPP 조건은 구독 1,000 + 롱폼 시청 4,000시간(12개월). 2027.2.1부터 신규 가입은 8,000시간(1년) 또는 쇼츠 2,000만 회(90일)로 오르고, 이미 가입한 채널은 영향이 없다. 쇼츠 피드 시청 시간은 시청 시간 요건에 안 들어간다. → **1월 31일 전에 4,000시간을 노린다.**
- **팬 전환:** 쇼츠만으로는 구독이 안 쌓인다(1,000만 회 쇼츠 채널의 구독 6,600명). 매일 쇼츠 3편이 롱폼으로 사람을 보내는 통로가 되게 한다.
- **우리 강점:** 레퍼런스 롱폼에서 사람들이 되돌려 본 구간은 전부 "내 돈으로 한 계산"이었다.

## 2. 목표 (첫 4편 기준으로 점검하는 목표치, 근거 있는 기준은 아님)
- 평균 시청 시간 5분 이상, 평균 시청 지속률 35% 이상, 노출 클릭률 5% 이상
- 1월 31일까지 누적 시청 4,000시간 = 주 1편 × 약 13편, 편당 평균 6분 시청이면 편당 약 3,100회

## 3. 1편에서 정한 것 (계획안과 달라진 점)
| 계획안 | 실제 LF.01 | 이유 |
|---|---|---|
| 1억당 5년 뒤 남는 돈 | **회수 기간 = 창업비 ÷ 한 달 현금** | 가게 크기가 달라도 한 숫자로 비교되고, 장비 수명(5년·PC 3년)과 바로 견줄 수 있다. "몇 달 만에 본전?"은 상담에서 실제로 듣는 말이다 |
| 출발점: 퇴직금 1억 | 소상공인 평균 창업비 **8,300만 원** (2024 실태조사) | 출처 있는 평균 숫자로 시작 |
| 9개 중 8개 | 헬스장 제외 (창업비 근거가 가장 약함) | — |
| 창업비: 쇼츠 장비비 | 보도·공정위 자료로 새로 잡음 (보증금 제외, 권리금 미포함) | 편의점·저가 커피도 근거를 찾음 |
| 2라운드: 업종별 반전 요인 | 공통 조건 **매출 −20%** + 실제 있었던 유행(탕후루)·포화(사진관) | 같은 조건이라야 순위가 공정하다. 폐업자 64%가 매출 40% 넘게 줄고 폐업 → 20%는 순한 가정 |
| 체크리스트 ④ 내 시급 ⑤ 매출 −30% | ④ 장비 수명과 비교 ⑤ 매출 −20% · 시급은 보너스 라운드 | 영상 안 계산과 맞춤 |
| 결론 미정 | "창업은 가게를 사는 게 아니라, 본전까지의 시간을 사는 거였던 거죠." | 비유(자판기)와 이어짐 |

## 4. 형식 (LF.01 기준, 다음 편도 같은 틀)
- 1920×1080 30fps, H.264 + AAC, −14 LUFS · 길이 14~15분
- 구조: 떡밥 3개 오프닝(1분) → 계산 규칙과 비유 하나 → 1라운드(잘 될 때) → 시그니처 → 2라운드(현실, 반전) → 보너스 → 함정 → 체크리스트 5개 → 한 줄 결론 → 댓글 질문 → 최종 화면 20초
- 장 시작마다 3초 장 제목 카드, 오른쪽 위에 장 이름 고정, 문장 자막(2줄 넘으면 넘김)
- 계산기 마스코트 '계산이'(표정 6개: 기쁨·생각·놀람·걱정·으쓱·손 흔들기)를 오프닝·결론·썸네일·최종 화면에 쓴다
- 배경음: 장면마다 drive / calm / dark 세 가지, 장 제목·최종 화면에서만 크게
- 썸네일: 화면 가득 장면(셔터·돈·계약서) + 아래 큰 글자 2줄(흰 + 노랑/빨강) + 근거 딱지(공정위 자료 등) + 계산이 표정. 사실형·질문형·인용형 3안 (`docs/references.md` 썸네일 분석)
