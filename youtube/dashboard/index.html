채널 연결 (YouTube Data API v3)

API 키를 넣으면 구독자·조회수·좋아요·업로드 날짜를 자동으로 가져옵니다. 키는 이 브라우저에만 저장되고, 파일 안에는 저장되지 않습니다.

  1. Google Cloud 콘솔에서 프로젝트를 만들고 YouTube Data API v3를 사용 설정
  2. 사용자 인증 정보 → API 키 만들기
  3. 키 제한 → API 제한: YouTube Data API v3만 선택 (보안)
