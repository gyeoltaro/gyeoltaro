# 영상 레퍼런스 연구 (2026-11-10)

## 무엇을 봤나
- 썸네일 연구와 같은 '잘 된 영상'(최근 1년 한국 경제 롱폼, 구독자 대비 조회수 3배 이상·5만 회 이상) 중 상위 45개.
- 영상마다 유튜브가 자동으로 만든 중간 장면 3장(약 25%·50%·75% 지점)을 내려받아 **135장**을 눈으로 비교. 길이·챕터는 YouTube Data API.
- 영상 전체를 내려받거나 대본을 가져오지는 않았습니다(남의 영상 복제 없음, 구성 원칙만 분석).

## 숫자
- 길이 중앙값 **28.9분** (우리 EP.10~12: 25~28분 — 비슷한 수준).
- 챕터를 단 영상 19/45개(42%), 챕터 수 중앙값 8개, 챕터 평균 길이 약 3.8분 (우리: 7~8개, 3~4분 — 비슷).

## 영상 형식 분류 (45개)
| 형식 | 대략 비율 | 예 |
|---|---|---|
| **AI·일러스트 그림 슬라이드 + 내레이션** (얼굴 없음) | 약 절반 | 장면마다 장소 그림, 막대 인간·만화 인물 |
| 인터뷰·대담(사람 출연) | 약 1/3 | 방송사·대형 채널 |
| 강의·문서형(흰 배경 인포그래픽, 책 장면) | 나머지 | |
→ 우리와 같은 **얼굴 없는 해설 채널**은 첫 번째 형식이 표준입니다.

## 잘 된 '얼굴 없는' 영상의 공통점 (우리와 비교)
| | 잘 된 영상 | 우리 (EP.09~12) |
|---|---|---|
| 배경 | **밝고 따뜻한 장소 그림**(사무실·도시·거실·은행·시장)이 화면 전체 | 어두운 단색 + 격자 |
| 캐릭터 | 막대 인간이 **장면 안에서 연기**(책상에 앉음, 차트 가리킴, 머리 감싸기) | 화면 옆에서 태블릿 들고 서 있음 |
| 화면 위 글자 | **적음**. 그림 속 짧은 라벨·말풍선, 가끔 인포그래픽 장면 | 정보 카드가 화면 대부분 |
| 그림 전환 | 문장(5~10초)마다 새 그림 + 느린 확대(켄 번즈) | 장면(20~40초)마다, 안에서 요소가 하나씩 등장 |
| 자막 | 아래 가운데 한 줄, 흰 글자 + 검은 테두리 | 같음 (유지) |
| 리듬 | **이야기 그림 ↔ 정보 그림**이 번갈아 나옴 | 정보 카드가 연속 |

→ 우리 장점(정확한 숫자·도표·모션)은 유지하고, **장소 배경 · 장면 안의 캐릭터 · 이야기 장면**을 섞는 방향으로 업그레이드합니다.

## 엔진에 반영한 것 (`meta.look = "story"`)
1. **장소 배경 7종** (`studio/envs.py`): 사무실·도시·은행·거실·교실(칠판)·시장·야경. 모두 코드로 그린 밝은 벡터 그림, 장면마다 느린 확대·이동(켄 번즈). 파트(챕터)가 바뀔 때마다 장소가 바뀜(`meta.envs`로 순서 지정, 장면별 `env`로 개별 지정).
2. **보드**: 정보 카드(도표·시세판·저울 등)는 장소 안의 '모니터/보드' 위에 올라가서 밝은 배경에서도 글자가 잘 읽힘.
3. **이야기 장면 `stage`** (새 그림 종류): 캐릭터가 화면 가운데 크게 서서 말풍선으로 한마디 하고, 소품 아이콘(집·동전·차트 등)이 장면 안에 튀어나옴. 글자는 말풍선 한 줄 + 큰 한마디만. → 정보 장면 2~3개마다 1개씩 끼워 넣어 리듬을 만듦.
4. 어두운 테마·격자·떠다니는 기호는 스토리 룩에서는 끔(밝은 장면과 충돌).

## 하지 않은 것 (이유)
- AI 이미지 생성: 이 환경에서 쓸 수 없고, 같은 그림체를 유지하기 어려움 → 코드로 그린 장소 그림으로 대신.
- 사람 출연·인터뷰 형식: 채널 콘셉트(캐릭터 해설)와 다름.
- 남의 그림·영상 장면 사용: 저작권·재사용 콘텐츠 정책 위험.
