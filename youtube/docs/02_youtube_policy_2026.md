# 유튜브 규정 정리 (2026-11 기준) + 우리 제작 방식의 대응

> 공식 도움말과 주요 보도를 기준으로 정리했습니다. 정책은 자주 바뀌므로 업로드 전에 출처 링크를 다시 확인하세요.

## 1. 바뀐 규정 핵심

### ① 비진정성(Inauthentic) 콘텐츠 — 수익 창출 불가
- 2025-07-15: '반복 콘텐츠' 정책 이름이 **'비진정성 콘텐츠'**로 바뀌었습니다(대량 생산·반복 콘텐츠).
- **2026-07-16 명확화**: 수익 창출 불가 유형을 3가지로 정리했습니다. 판단은 **채널 단위**로 하며,
  해당 유형이 "너무 많으면" 파트너 프로그램에서 제외됩니다.
  1. **일반적·반복적·템플릿형**: 영상마다 변화가 거의 없는 경우, 서사·해설·교육적 가치가 없는
     이미지 슬라이드쇼나 스크롤 텍스트, 일반 템플릿으로 찍어낸 AI 콘텐츠
  2. **불쾌하거나 감정을 조작하는 자극적 콘텐츠**
  3. **민감 주제(건강·법률·금융·정치)를 다루는 AI 페르소나**: 사람 전문가처럼 행세하며 조언하는 경우
     - 공식 예시: *"금융 가이드, 투자 팁, 자산 관리 조언을 하는 AI 생성 팟캐스트 진행자"*
- 허용 예시: AI로 내가 만든 고유 캐릭터·서사를 시각화, AI로 대본 다듬기·배경 생성,
  같은 인트로/아웃트로(본문이 매번 다르면 OK)
- **AI 사용 자체는 금지가 아닙니다.** "TTS를 쓰면 수익 정지"는 사실이 아니며, 문제는 반복성·독창성 부족입니다.

### ② 재사용 콘텐츠 (변경 없음)
- 남의 콘텐츠를 거의 그대로 다시 쓰는 경우, **내가 만들지 않은 자료를 읽기만 하는 경우** → 허락을 받았어도 불가
- 내 해설과 스토리를 더하면 허용

### ③ AI 생성·합성 콘텐츠 공개 라벨
- **사실적으로 보이는** 합성 콘텐츠는 공개 필수: 실존 인물이 하지 않은 말·행동, 실제 사건·장소 조작, 사실적인 가짜 장면
- **공개 불필요**: 명백히 비현실적인 애니메이션, 대본·썸네일·제목 작성 보조, 자막 생성, 본인 목소리 복제
- 유튜브가 C2PA 메타데이터나 내부 감지로 **라벨을 자동으로 붙일 수 있습니다**(2026년 강화).
- 라벨을 붙여도 노출·수익에는 불이익이 없다는 것이 유튜브의 공식 입장입니다.

### ④ 낚시성 제목·썸네일(클릭베이트) 단속
- 2024-12 인도에서 시작해 확대될 예정입니다. 제목·썸네일이 약속한 내용이 영상에 없으면 삭제될 수 있습니다.
  특히 '속보/긴급' 형태의 시사 콘텐츠가 주요 대상입니다.

### ⑤ 파트너 프로그램(YPP) 가입 기준 강화 — 2027-02-01부터 신규 신청 (보도 기준)
- 구독자 1,000명 + **공개 시청 8,000시간(최근 12개월)** 또는 쇼츠 조회수 2,000만 회(90일)
  - 현재 기준은 4,000시간 / 1,000만 회
- 기존 회원은 2027-01-31까지 새 약관에 동의해야 한다고 보도됨(세부 유지 조건은 공식 확인 필요)

### ⑥ 기타
- 2026-10-01부터 쇼츠 추천에서 오리지널 쇼츠를 우대하고, 남의 클립을 재업로드하는 채널은 도달이 줄어듭니다.
- 2026-10부터 일부 국가(미국·인도·인도네시아)에서 수익 지급 기준액을 20달러로 낮추는 실험을 하고 있습니다(한국 미포함).

## 2. 우리 파이프라인의 대응

| 리스크 | 대응 (이 저장소에 구현됨) |
|---|---|
| 템플릿·반복 콘텐츠 | 매 화 주제·대본·장면 구성이 모두 다르고, 사실 데이터를 직접 검수합니다. 20종 장면 애니메이션 + 캐릭터 연기로 구성하며, 정지 이미지 슬라이드쇼는 쓰지 않습니다. |
| AI 페르소나 × 금융 | 캐릭터는 **명백한 만화 마스코트**이고 '전문가'라고 자칭하지 않습니다. 투자 권유 없이 **경제 원리 교육**만 다루며, 영상 속(PART 6)과 설명란에 고지문을 넣습니다. 운영자가 검수했다는 사실도 명시합니다. **가장 안전한 방법은 본인 목소리 녹음**입니다 → `voice/` 폴더 기능 |
| 재사용 | 남의 영상·자료를 낭독하지 않습니다. 레퍼런스는 **포맷만** 참고하고 대본은 새로 씁니다. 출처는 설명란에 표기합니다. |
| 클릭베이트 | 제목의 약속("15분", "모든 것")을 실제 영상과 맞춥니다. 영상 길이는 빌드할 때 계산됩니다. `[긴급]` 반복은 쓰지 않습니다. |
| 저작권·초상권 | 폰트는 OFL(상업 이용 가능)입니다. 효과음·배경음은 코드로 직접 합성합니다. 실존 인물 사진·타사 로고는 쓰지 않습니다. |
| 공개 라벨 | 애니메이션 캐릭터이며 실존 인물·사건을 사실처럼 합성하지 않으므로 '아니요'가 기본값입니다. 다만 사실적인 AI 영상을 넣으면 '예'로 바꿔야 합니다. |
| TTS 라이선스 | 기본 엔진인 edge-tts는 무료지만 공식 상용 라이선스가 아닙니다. 수익화 전에 **본인 녹음이나 상용 TTS**로 바꾸는 것을 권장합니다. |

## 3. 업로드 전 체크리스트

- [ ] 제목·썸네일의 약속이 영상 내용과 일치하는가 (분량, 숫자, "모든 것")
- [ ] 모든 수치에 출처가 있고, 날짜가 명시돼 있는가 (예: "2022년 6월 미국 CPI 9.1%")
- [ ] 특정 종목·상품 추천, 수익 보장 표현이 없는가
- [ ] 캐릭터가 사람 전문가인 척하지 않는가 ("10년 차 애널리스트입니다" 금지)
- [ ] 실존 인물 사진, 타사 로고, 보도사진을 쓰지 않았는가
- [ ] 이전 영상과 구성·대본이 충분히 다른가 (같은 틀에 단어만 바꾸지 않았는가)
- [ ] '변경되거나 합성된 콘텐츠' 질문에 올바르게 답했는가
- [ ] 설명란에 챕터(0:00 시작, 3개 이상, 각 10초 이상)·출처·고지문이 있는가
