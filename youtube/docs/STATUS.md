## 이어 가는 법 (작업자가 바뀌거나 새 대화일 때)

1. 저장소의 이 브랜치(또는 합쳐진 기본 브랜치)를 엽니다. `youtube/docs/` 가 보이면 맞습니다.
2. 이 파일 → [`PLAYBOOK.md`](PLAYBOOK.md) 순서로 읽습니다.
3. `youtube/` 에서 `python -m studio.ep status` 로 편 목록과 다음 번호를 확인합니다.
4. 영상 파일(`out/video.mp4`)은 저장소에 없습니다. 예전 편의 영상이 필요하면 `python -m studio.ep render <폴더>` 로 다시 만듭니다.
5. 조회·벤치마크 도구를 쓰려면 YouTube Data API 키가 필요합니다([`PLAYBOOK.md`](PLAYBOOK.md) 1장). 없어도 제작은 됩니다.
