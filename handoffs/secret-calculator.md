## 5) 규칙과 선호
- "계속", "만들어줘" 같은 짧은 지시엔 묻지 말고 끝까지 진행해요.
- 결과는 파일(MP4·썸네일·자막)로 보내고, 업로드 문구는 제목·설명·태그·고정 댓글·스튜디오 칸까지 다 써요.
- 문서를 보여 달라고 하면 아티팩트 페이지(복사 버튼)로 만들어요.
- API 키는 파일·저장소에 절대 넣지 않아요. 환경변수 `GOOGLE_TTS_API_KEY`로만 쓰고, 커밋 전에 `AIza` 패턴을 grep으로 검사해요.
- YouTube 봇 확인 우회나 영상 다운로드는 하지 않아요.
- 실제 상표·실존 인물 사진은 쓰지 않아요. 영상 속 브랜드는 '한 본사'로 써요.
- 수치는 원문을 확인하고, 불확실하면 '예시'로 표시해요.
