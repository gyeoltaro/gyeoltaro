2026-10-30에 이전 세션(session_01QLirhsXf6iWZkEr2xUCFuK)이 쓴 메모예요. 대화가 길어져(약 60만 토큰) 새 세션으로 이어가요.

## 1) 한 줄 요약
조선 봉수대를 지키는 1인 개발 무료 디펜스 웹게임이에요. 화면과 로직은 순수 JS(캔버스)이고, 계정·랭킹 서버는 Cloudflare Worker와 D1이에요.

## 2) 저장소와 주요 파일
- 저장소: github.com/BHdefence/bonghwa, `main` 브랜치(BHdefence.github.io로 옮겨졌지만 push는 그대로 돼요).
  - main에 push하면 GitHub Pages로 사이트가 배포돼요.
  - `api/**`가 바뀌면 "계정 서버 배포" Action이 Worker를 배포해요.
- 주요 파일
  - `index.html`: CSS와 DOM. 배포할 때마다 `?v=` 3곳을 올려야 해요(현재 20261018-2).
  - `data.js`: 물건, 적, 난이도, 봉수로(ROUTES/STAGES), 조합(COMBOS), 업적(ACHS), 봉수 소식(NEWS).
  - `art.js`: 도트 그림 · `game.js`: 게임 로직, UI, Cloud 저장 동기화.
  - `api/worker.js`, `api/schema.sql`, `privacy.html`.
- 시험: `index.html#dev`로 열면 `window.__bh`를 쓸 수 있어요. localStorage `bonghwa-api`로 API 주소를 바꿔 로컬에서 시험해요.

## 5) 대표님 규칙과 선호
- 항상 한국어, 쉬운 해요체로 답해요.
- 토큰과 키는 GitHub Secrets에만 둬요. 채팅에 붙여 넣지 않아요.
- D1은 SELECT만 자유롭게 해요. 데이터를 바꿀 때는 명시적 허락을 받아요. 운영 DB 전체 복원 같은 작업은 대표님이 직접 해요.
- 디시 글 본문에는 링크를 넣지 않아요(하루 정지를 받은 적이 있어요).
- 봉수 소식에 저승길 III 피해 +2% 조정은 언급하지 않아요.
- 주간 랭킹전은 매주 일요일 22시(KST)에 새로 시작해요. 물건과 적이 바뀌는 배포는 그 뒤에 하는 게 원칙이에요(대표님이 "지금 바로"라고 하면 따라요).
- 개발자 계정(ksjer1124, kkjlg)은 첫 완주자 자리에서 빠져요.
- PR은 요청이 있을 때만 만들어요. main에 바로 커밋하고 push하는 흐름이에요.

## 6) 주의할 점
- kkjlg 저장 데이터가 사라진 사고가 있었어요. 판수 기준 비교(aheadOf), 서버 409, saves_bak 14일 사본으로 막았어요. 저장 동기화 코드를 고칠 때 이 장치가 깨지지 않게 조심해요.
- `?v=`를 올리지 않으면 캐시 때문에 옛 파일이 보여요.
- `josa()`는 단어와 조사를 함께 돌려줘요. 단어를 앞에 또 붙이면 이름이 두 번 나와요.
- `worker.js`의 TITLES는 data.js ACHS의 칭호와 반드시 같아야 해요.
- 쇼츠를 녹화할 때 게임 iframe의 타이머는 실제 시간으로 흘러요. 알림 같은 연출은 직접 붙잡아 둬야 해요.
- 컨테이너 안의 파일 경로는 대표님이 열 수 없어요. 파일은 아티팩트(받기 버튼)로 전달해요.
- 밸런스 봇 결과는 판마다 크게 흔들려요. 여러 판의 평균으로 판단해요.
- 키트 원본, 쇼츠 생성기(make3.mjs), 밸런스 봇(bal.mjs)은 이전 세션의 임시 폴더에만 있었어요. 새 세션에는 없어요. 키트는 아티팩트 읽기로 원본을 다시 받을 수 있어요.
