## 후보 1. 파일이 안 올라가는 직장인 문서 도구함 (한국)

핵심 셀링 포인트: **회사 파일이 서버로 올라가지 않고 브라우저 안에서만 처리된다.**
회사 보안 규정 때문에 업로드형 변환 사이트(iLovePDF 등)를 못 쓰는 직장인을 노린다.

### 대표 도구 1: 엑셀 개인정보 일괄 마스킹 (먼저 만들 것)
- 엑셀 파일을 넣으면 주민번호·전화번호·이름·이메일·계좌 열을 자동으로 찾아 한 번에 가린다.
  - 예: `홍*동`, `010-****-5678`, `900101-1******`
- 대상: 인사, 총무, 영업지원, 학교 행정 등 개인정보 파일을 외부에 보내야 하는 사람
- 현재 대안: 블로그 보고 REPLACE 함수·VBA 매크로를 직접 짬. 텍스트 붙여넣기형 웹 도구는 있으나
  엑셀 파일을 통째로 넣는 무료 웹 도구는 검색에서 찾지 못함
- 주의: 마스킹 결과는 사용자가 최종 확인해야 한다는 안내 필요

### 대표 도구 2: 한글(HWP) 표 → 엑셀
- 대상: 공공기관, 학교, 공기업 직원
- 현재 대안: HTM 저장 후 엑셀로 열기(병합 셀 깨짐), 개인이 만든 윈도우 프로그램(hwp2excel)
- 브라우저에서 바로 되는 도구는 찾지 못함
- 구현 순서: HWPX(ZIP+XML, 쉬움) 먼저 → HWP 5.0(바이너리) 나중

### 경쟁 있음: 여러 엑셀 파일 취합
- 엑셀 파워쿼리(무료 내장), XLMerge 매크로, 업로드형 사이트(Aspose, unidago)가 이미 있음

### 수익 구조
- 무료: 파일 1개, 100행까지
- Pro: 여러 파일 일괄, 행 무제한, 마스킹 규칙 저장
- 가격: 평생 1~3만 원대 또는 월 구독
- 결제: 처음엔 Lemon Squeezy(해외 카드), 이후 사업자등록 + 토스페이먼츠 등 국내 결제

### 한계
- 한국 전용(HWP, 주민번호). 대신 해외 경쟁자가 들어오기도 어려움

## 후보 2. 공문서 표기 검사·자동 교정기 (한국)

- 대상: 공무원, 교사, 공공기관·공기업 직원, 공공기관과 일하는 협력업체
- 하는 일: 공문 본문을 붙여넣거나 HWPX 파일을 넣으면 공문서 작성 규칙 위반을 찾아 표시하고 한 번에 고쳐 준다
  - 날짜: `2026.10.12` / `2026년 10월 12일` → `2026. 10. 12.` (월·일 앞 0 생략)
  - 시간: `오후 2시 30분` → `14:30` (24시각제, 쌍점)
  - 항목 기호 순서: `1.` → `가.` → `1)` → `가)` → `(1)` → `(가)` → `①` → `㉮`
  - 붙임 표기: 첨부물이 하나면 번호 생략, 여러 개면 `1.` `2.`로 번호
  - 끝 표시: 마지막 글자에서 두 타 띄우고 `끝.`, 표로 끝나면 `이하 빈칸`
  - 금액: `금113,560원(금일십일만삼천오백육십원)` 형식
- 현재 대안: 맞춤법 검사기(바른 한글, 네이버, 한/글 내장)만 있음. 공문 양식 규칙까지 검사하는
  전용 도구는 두 번 검색해도 찾지 못함. 사람들은 블로그·교육청 PDF를 보고 눈으로 확인
- 규칙이 정해져 있어서 AI 없이 브라우저에서 정확하게 구현 가능
- 규칙 기준 문서: 「행정업무의 운영 및 혁신에 관한 규정」, 행정안전부 「행정업무운영 편람」(원문 확인 필요)
- 수익: 개인이 돈을 낼 의향은 낮을 수 있음 → 무료로 검색 유입을 모으고(광고),
  HWPX 파일 검사·일괄 교정을 Pro로
- 시너지: 후보 1(HWP 표→엑셀, 개인정보 마스킹)과 같은 사람들(공공·학교 사무직)이 쓰는 도구라
  하나의 "공공·학교 사무 도구함"으로 묶으면 공문 검사기가 유입, 마스킹·HWP 변환이 유료 상품이 됨
